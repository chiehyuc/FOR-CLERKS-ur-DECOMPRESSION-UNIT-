# Clerk Decompression Unit v2

A tiny browser-game-style decompression facility for medical clerks.

Rooms:
- Biohazard Disposal: catch and discard clinical nonsense, but don't throw away the rare good memories.
- Where Should I Stand™: a spatial survival simulation.
- The Pager: autonomic conditioning, but make it useless.
- Spot Question Me™: voluntarily locate the boundary of your knowledge.
- Documentation Services: add words without adding information.
- Elevator: unavoidable attending exposure.
- Emergency Button: explicitly do not press.
- Exit: clock out and go be a person.

## Deploy
Put `index.html`, `style.css`, and `app.js` at the root of a GitHub repository.
Settings → Pages → Deploy from a branch → main → /(root).

No build step required.

This is a humor project, not medical advice or a mental-health intervention.
